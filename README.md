## Featured project

### [CraftVerse](https://github.com/NexoraXD/CraftVerse)

An Android-native Minecraft content platform and creator studio built with **Kotlin** and **Jetpack Compose**.

- Separate workflows for Minecraft Java Edition and Bedrock Edition.
- Creator tools, including texture and JSON editing.
- Content discovery, downloads, and a local library.
- A modular foundation for future provider integrations.

**Repository status:** Private development repository. The project is actively evolving; features not yet connected are documented in its roadmap.
